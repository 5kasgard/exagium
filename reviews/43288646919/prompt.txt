# Pre-registration: bench-4, one free model in five agent harnesses

Written 2026-11-13 before any registered run. Author: Claude Opus (chose the arms, wrote the rules; not an arm). It follows `claude/forge-harness-research.md` in the project and bench-3 (still running).

**Every rule below is code in `router/bench4/decide.py`.** `decide.py selftest` runs before each batch and checks that every ending gets exactly one label and every rule returns a verdict. Where this text and the code differ, the code is the rule and the difference is a defect to report. The status table (`router-runs:bench/bench4/STATUS.md`) is generated by that code.

## Why
A published study ("The Scaffold Effect", ICML 2026 workshop, arXiv 2607.22585) held the model fixed and found up to a 40× difference in tokens per solved task between Goose, OpenCode and the OpenHands SDK, with pass rates within 0–8 points. Our free pools are limited by requests (OpenRouter, 1,000 a day) and, elsewhere, by tokens. If a harness solves our tasks for far fewer tokens or calls, the router should use it.

## Question
With the model held fixed, which harness solves exagium's tasks for the fewest tokens per solved task, without solving fewer?

## Arms (the harness is the only thing that changes)
| Arm | Harness | Version |
|---|---|---|
| openhands (base) | OpenHands SDK default agent, tools in-process, no browser | 1.61.0 |
| mini | mini-swe-agent, default `mini.yaml` | 2.4.6 |
| goose | Goose, `developer` builtin, auto mode | 1.59.0 |
| pi | Pi, print mode, default tools and thinking level | 1.5.2 |
| opencode | OpenCode `run`, edit and bash allowed, web fetch denied | 1.19.5 |

- **Model, the same for all:** `nvidia/nemotron-3-ultra-550b-a55b:free` (bench-2 3/3 clean; bench-3 4/4 clean so far, pilot included). The meter rewrites every call to it, whatever model a harness asks for. OpenCode, for one, asks for a paid model for its titles by default.
- **Each harness runs at its own documented defaults:** its own system prompt, tools and settings. Tuning one would bias the comparison. That is also how a user would meet it.
- **The control** (no agent) runs once per task and must fail all three, or the run is void.

## Same for every arm
- The same image, built from the same commit, holding all five harnesses.
- The same task text (bench-3's T1–T3, with "which is in /workspace" added).
- The same grader, hidden tests and pass-to-pass lists.
- **The same budget:** **80 model calls**, counted by the meter, which refuses the 81st. The attempt is stopped 30 s after the first refusal. Wall cap: 35 minutes.
- **The same seal:** the container's only network peer is the meter on the host. Nothing is forwarded (no DNS, no internet), and the key never enters the container. Before each attempt, a probe from the same image must reach the meter and be refused by 1.1.1.1 and github.com, or the attempt doesn't start.

## Changed from bench-3, and why
- **Calls and tokens are counted by one meter** that all harnesses go through, not by each harness's own logs. Calls are forwarded requests; tokens are from the provider's usage block on each response. This fixes bench-2's broken call count for good.
- **Tools run in the agent's container** for every arm, OpenHands included (bench-3 ran OpenHands' tools in a separate Agent Server container). So the OpenHands arm here isn't identical to bench-3's arm A.
- **"Clean" is by construction:** no attempt can reach anything but the meter. Refused outbound connections are counted and reported per attempt; most come from the harnesses themselves (update checks, telemetry), not the agent.

## Endings (one per attempt; the first match wins)
1. `control`.
2. `skipped_budget`: the allowance guard refused it. Not a result.
3. `seal_failed`: the pre-attempt probe failed, so the attempt didn't start. Not a result; reported.
4. `harness_crash`: no run record, or the container never started.
5. `provider_error`: the provider answered a forwarded call with an error, and the attempt didn't pass. Not counted; retried, and after 3 the cell is `provider_cut` and left out.
6. `call_cap`: stopped at the 80-call cap.
7. `timeout`: stopped at the wall cap.
8. `exited`: the harness ended on its own.

Counted attempts are 4, 6, 7 and 8. A pass despite a provider error still counts.

## Repeats, batches, budget
- 3 tasks × 5 arms × 3 repeats = 45 attempts, plus 3 controls.
- Batches work as in bench-3: the provider's count of free requests left decides how many attempts fit (`(left − 20) // 80`, at most 10). Each attempt checks again and is skipped under 180 left.
- Order: controls, then repeat 1 of every task and arm, then repeat 2, then 3.
- Worst case 45 × 80 = 3,600 requests. **bench-3 shares the same allowance;** both workflows are in one concurrency group, so they never run at once.
- **Futility:** a non-base arm with no pass in its first 6 counted attempts (repeats 1 and 2 of each task) stops. The base arm never stops.

## Decisions, fixed now
- **Pass:** the hidden test passes with no pass-to-pass test broken.
- **Per arm:** passes over counted attempts, with a Clopper-Pearson 95% interval.
- **Tokens per pass** (the primary measure) = total tokens (prompt + completion) over all of an arm's counted attempts ÷ its passes, as in the study above. **Calls per pass** likewise; that is the measure the OpenRouter limit binds on.
- **Cheaper:** the 95% percentile-bootstrap interval of (arm's tokens per pass ÷ base's tokens per pass) lies wholly below 1.
  - Attempts are resampled within each task, separately for each arm. B = 10,000, seed 20261113.
  - If more than 10% of an arm's calls lack a usage block, its tokens are "unmeasured" and it can't be called cheaper.
- **Worse:** a one-sided Fisher exact test gives p < 0.05 that the arm's pass rate is below the base's.
- **Switch rule:** when complete and not void, switch the router's default harness to the arm that is cheaper, not worse, and uses at most 1/3 of the base's tokens per pass. If several qualify, choose the lowest token ratio. Otherwise, no switch.
- **Also reported, with no verdict:** calls per pass and their ratio to the base; median calls, tokens and wall time; endings per arm; where each attempt first went green by its own tests and by the hidden test (in model calls); and refused connections.

## Known limits, stated now
- **Three tasks, one file, n = 9 per arm.** The Fisher test only catches large drops in pass rate. "Not worse" here means "no large drop shown", not "equal".
- **Harness defaults differ in hidden ways:** thinking level, temperature, context handling and retries. That is the treatment, not a confound to remove, but it means a result is about these versions at their defaults.
- **The meter rewrites model names.** A harness that asks a second model for side calls (titles, summaries) gets the arm's model instead. That is counted in its calls and tokens, which is right for cost but may change how that harness behaves.
- **Requests and tokens differ:** a harness can use fewer tokens but more calls. Both are reported; the switch rule uses tokens, because calls per pass are reported anyway and token-limited pools are the ones they would unlock.
- The free model's behaviour can drift during the run. Batches interleave the arms, so drift falls on all of them.

## Spend
$0. OpenRouter free model only (the workflow refuses a slug without `:free`). GitHub-hosted runners, for this project's own development and testing.

MODEL = "nvidia/nemotron-3-ultra-550b-a55b:free"
BASE = "openhands"                       # the current harness, the one every other arm is compared with
ARMS = ["openhands", "mini", "goose", "pi", "opencode"]
TASKS, REPS = ["T1", "T2", "T3"], 3
CAP, MARGIN, BATCH_MAX = 80, 20, 10
FUTILITY_N, MAX_TRIES = 6, 3
SEED, B = 20261113, 10000
ENDS = ["control", "skipped_budget", "seal_failed", "harness_crash", "provider_error", "call_cap", "timeout", "exited"]
COUNTED = {"harness_crash", "call_cap", "timeout", "exited"}


def classify(run, calls, passed, control=False):
    """One label per attempt; the first matching line wins."""
    if control:
        return "control"
    if run.get("skipped"):
        return "skipped_budget"
    if run.get("ending") == "seal_failed":
        return "seal_failed"
    if not run or run.get("ending") in (None, "start_failed"):
        return "harness_crash"
    upstream_bad = any(isinstance(c.get("status"), int) and c["status"] != 200 for c in calls)
    if upstream_bad and not passed:
        return "provider_error"
    return {"call_cap": "call_cap", "timeout": "timeout", "exited": "exited"}.get(run["ending"], "harness_crash")


def _binom_cdf(k, n, p):
    return sum(math.comb(n, i) * p ** i * (1 - p) ** (n - i) for i in range(k + 1))


def interval(k, n, alpha=0.05):
    if n == 0:
        return 0.0, 1.0

    def solve(f):
        lo, hi = 0.0, 1.0
        for _ in range(60):
            mid = (lo + hi) / 2
            lo, hi = (mid, hi) if f(mid) else (lo, mid)
        return (lo + hi) / 2
    low = 0.0 if k == 0 else solve(lambda p: 1 - _binom_cdf(k - 1, n, p) < alpha / 2)
    high = 1.0 if k == n else solve(lambda p: _binom_cdf(k, n, p) > alpha / 2)
    return low, high


def fisher_less(a, n1, b, n2):
    """One-sided Fisher exact p that arm 1's rate (a/n1) is below arm 2's (b/n2)."""
    K, N = a + b, n1 + n2
    def hyp(x):
        return math.comb(n1, x) * math.comb(n2, K - x) / math.comb(N, K)
    return sum(hyp(x) for x in range(max(0, K - n2), a + 1))


def load(d):
    return [json.load(open(f)) for f in sorted(glob.glob(os.path.join(d, "*", "*", "result.json")))]


def cells(results):
    done, tries = {}, {}
    for r in results:
        key = (r["task"], r["arm"], r["rep"])
        if r["end"] in COUNTED or r["end"] == "control":
            done.setdefault(key, r)
        elif r["end"] == "provider_error":
            tries[key] = tries.get(key, 0) + 1
    for key, n in tries.items():
        if key not in done and n >= MAX_TRIES:
            done[key] = "provider_cut"
    return done


def arm_rows(done, arm):
    return [v for (t, a, r), v in sorted(done.items(), key=lambda kv: (kv[0][2], kv[0][0])) if a == arm and v != "provider_cut"]


def futile(done, arm):
    rs = arm_rows(done, arm)
    return arm != BASE and len(rs) >= FUTILITY_N and not any(r["passed"] for r in rs[:FUTILITY_N])


def plan(results, remaining):
    done = cells(results)
    todo = [{"task": t, "arm": "control", "rep": 0} for t in TASKS if (t, "control", 0) not in done]
    for rep in range(REPS):
        for t in TASKS:
            for a in ARMS:
                if (t, a, rep) not in done and not futile(done, a):
                    todo.append({"task": t, "arm": a, "rep": rep})
    n_agents = max(0, min(BATCH_MAX, (remaining - MARGIN) // CAP))
    out, used = [], 0
    for c in todo:
        if c["arm"] == "control":
            out.append(c)
        elif used < n_agents:
            out.append(c); used += 1
    return out, len([c for c in todo if c["arm"] != "control"])


def per_pass(rows, key):
    passes = sum(r["passed"] for r in rows)
    total = sum(key(r) for r in rows)
    return total / passes if passes else math.inf


def boot_ratio(rx, rb, key):
    """Percentile 95% interval of (cost per pass of X) / (cost per pass of BASE), resampling attempts within each task."""
    rng = random.Random(SEED)
    by = lambda rows: {t: [r for r in rows if r["task"] == t] for t in TASKS}
    bx, bb = by(rx), by(rb)
    vals = []
    for _ in range(B):
        sx = [rng.choice(v) for t, v in bx.items() for _ in v]
        sb = [rng.choice(v) for t, v in bb.items() for _ in v]
        a, b = per_pass(sx, key), per_pass(sb, key)
        vals.append(math.inf if math.isinf(a) else (0.0 if math.isinf(b) else a / b))
    vals.sort()
    return vals[int(0.025 * B)], vals[int(0.975 * B) - 1]


def tokens_known(rows):
    calls = sum(r["calls_ok"] for r in rows)
    missing = sum(r["tokens"]["calls_missing_usage"] for r in rows)
    return calls > 0 and missing <= 0.10 * calls


def status(results):
    done = cells(results)
    counted = [v for v in done.values() if v != "provider_cut" and v["end"] in COUNTED]
    controls = [v for v in done.values() if v != "provider_cut" and v["end"] == "control"]
    _, open_n = plan(results, 0)
    s = {"model": MODEL, "complete": open_n == 0 and len(controls) == len(TASKS), "open_cells": open_n, "counted": len(counted),
         "void": any(c["passed"] for c in controls),
         "control_ok": len(controls) == len(TASKS) and not any(c["passed"] for c in controls),
         "provider_cut": sorted(k for k, v in done.items() if v == "provider_cut"),
         "seal_checks_failed": sum(1 for r in results if r["end"] == "seal_failed"),
         "container_connections_refused": sum((r.get("egress") or {}).get("drops") or 0 for r in counted)}
    rb = arm_rows(done, BASE)
    tok = lambda r: r["tokens"]["total"]
    cal = lambda r: r["calls"]
    s["arms"], s["switch_candidates"] = {}, []
    for a in ARMS:
        rs = arm_rows(done, a)
        k = sum(r["passed"] for r in rs)
        lo, hi = interval(k, len(rs))
        v = {"passes": k, "n": len(rs), "low": round(lo, 3), "high": round(hi, 3),
             "tokens_known": tokens_known(rs) if rs else False,
             "tokens_per_pass": None if not k else round(per_pass(rs, tok)),
             "calls_per_pass": None if not k else round(per_pass(rs, cal), 1),
             "median_tokens": statistics.median([tok(r) for r in rs]) if rs else None,
             "median_calls": statistics.median([cal(r) for r in rs]) if rs else None,
             "median_wall_s": statistics.median([r["wall_s"] or 0 for r in rs]) if rs else None,
             "stopped_for_futility": futile(done, a),
             "ends": {e: sum(1 for r in rs if r["end"] == e) for e in ENDS if any(r["end"] == e for r in rs)}}
        if a != BASE and rs and rb:
            v["worse_p"] = round(fisher_less(k, len(rs), sum(r["passed"] for r in rb), len(rb)), 4)
            v["worse"] = v["worse_p"] < 0.05
            if v["tokens_known"] and tokens_known(rb):
                tl, th = boot_ratio(rs, rb, tok)
                pb = per_pass(rb, tok)
                v["token_ratio"] = None if math.isinf(pb) or not k else round(per_pass(rs, tok) / pb, 3)
                v["token_ratio_95"] = [tl, th]
                v["cheaper"] = th < 1.0
            else:
                v["token_ratio"], v["token_ratio_95"], v["cheaper"] = None, None, "unmeasured"
            cl, ch = boot_ratio(rs, rb, cal)
            pb = per_pass(rb, cal)
            v["call_ratio"] = None if math.isinf(pb) or not k else round(per_pass(rs, cal) / pb, 3)
            v["call_ratio_95"] = [cl, ch]
            if v["cheaper"] is True and not v["worse"] and v["token_ratio"] is not None and v["token_ratio"] <= 1 / 3:
                s["switch_candidates"].append(a)
        s["arms"][a] = v
    s["switch_to"] = (min(s["switch_candidates"], key=lambda a: s["arms"][a]["token_ratio"])
                      if s["complete"] and not s["void"] and s["switch_candidates"] else None)
    return s




=== meter.py ===
"""bench-4 meter: the only door between an agent container and the model. Standard library only.

usage: meter.py LISTEN_HOST PORT LOG_JSONL MODEL CAP
Env: OPENROUTER_API_KEY (stays on the host; containers get a dummy key).

Forwards POST {/v1,/api/v1}/chat/completions (and /responses, /messages) to https://openrouter.ai/api/v1/...
- Rewrites "model" to MODEL whatever the harness sent (every harness talks to the same worker) and
  adds usage accounting.
- Refuses with 429 once CAP model calls have been forwarded: the same budget for every harness,
  counted in model calls rather than in each harness's own idea of a "step".
- Logs one JSON line per call: t, path, status, stream, prompt/completion/cached/reasoning tokens,
  latency, and the generation id. Streaming responses pass through chunk by chunk; usage is read
  from the stream as it passes.
- GET /v1/models (and /api/v1/models) answers locally with MODEL, so harnesses that list models work.
- GET /meter/count returns {"calls": n} for the snapshot poller.
"""
import http.server, json, os, re, socketserver, sys, threading, time, urllib.error, urllib.request

HOST, PORT, LOG, MODEL, CAP = sys.argv[1], int(sys.argv[2]), sys.argv[3], sys.argv[4], int(sys.argv[5])
KEY = os.environ["OPENROUTER_API_KEY"]
UPSTREAM = os.environ.get("BENCH4_UPSTREAM", "https://openrouter.ai/api/v1")  # override only for local tests
lock = threading.Lock()
state = {"calls": 0, "refused": 0}
PATHS = re.compile(r"^(?:/api)?(?:/v1)?/(chat/completions|responses|messages|completions)$")


def log(rec):
    with lock, open(LOG, "a") as f:
        f.write(json.dumps(rec) + "\n")


def usage_of(obj):
    u = (obj or {}).get("usage") or {}
    d = u.get("prompt_tokens_details") or u.get("input_tokens_details") or {}
    c = u.get("completion_tokens_details") or u.get("output_tokens_details") or {}
    return {"prompt": u.get("prompt_tokens", u.get("input_tokens")),
            "completion": u.get("completion_tokens", u.get("output_tokens")),
            "cached": d.get("cached_tokens"), "reasoning": c.get("reasoning_tokens"), "cost": u.get("cost")}


class H(http.server.BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"

    def log_message(self, *a):
        pass

    def _send(self, code, obj):
        b = json.dumps(obj).encode()
        self.send_response(code)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(b)))
        self.end_headers()
        self.wfile.write(b)

    def do_GET(self):
        p = self.path.split("?")[0]
        if p == "/meter/count":
            with lock:
                return self._send(200, dict(state))
        if re.match(r"^(?:/api)?(?:/v1)?/models$", p):
            return self._send(200, {"object": "list", "data": [{"id": MODEL, "object": "model", "owned_by": "bench4",
                                                                  "context_length": 262144}]})
        self._send(404, {"error": {"message": "not served by the bench-4 meter"}})

    def do_POST(self):
        p = self.path.split("?")[0]
        m = PATHS.match(p)
        body = self.rfile.read(int(self.headers.get("Content-Length") or 0))
        if not m:
            log({"t": time.time(), "path": p, "status": "refused_path"})
            return self._send(404, {"error": {"message": "path not served"}})
        with lock:
            if state["calls"] >= CAP:
                state["refused"] += 1
                refuse = True
            else:
                state["calls"] += 1
                n = state["calls"]
                refuse = False
        if refuse:
            log({"t": time.time(), "path": p, "status": "refused_cap"})
            return self._send(429, {"error": {"message": f"bench-4 call cap of {CAP} reached", "code": 429}})
        try:
            req = json.loads(body or b"{}")
        except ValueError:
            return self._send(400, {"error": {"message": "body is not JSON"}})
        asked = req.get("model")
        req["model"] = MODEL
        if m.group(1) == "chat/completions":
            req["usage"] = {"include": True}
            if req.get("stream"):
                req.setdefault("stream_options", {})["include_usage"] = True
        stream = bool(req.get("stream"))
        t0 = time.time()
        up = urllib.request.Request(f"{UPSTREAM}/{m.group(1)}", data=json.dumps(req).encode(), method="POST",
                                    headers={"Authorization": f"Bearer {KEY}", "Content-Type": "application/json",
                                             "HTTP-Referer": "https://github.com/5kasgard/exagium", "X-Title": "exagium bench-4"})
        rec = {"t": t0, "n": n, "path": p, "asked_model": asked, "stream": stream}
        try:
            r = urllib.request.urlopen(up, timeout=600)
            status = r.status
        except urllib.error.HTTPError as e:
            r, status = e, e.code
        except Exception as e:  # network failure: the harness sees a 502
            rec.update(status=502, error=f"{type(e).__name__}: {e}"[:300], latency=round(time.time() - t0, 2))
            log(rec)
            return self._send(502, {"error": {"message": "upstream unreachable"}})
        ctype = r.headers.get("Content-Type", "application/json")
        self.send_response(status)
        self.send_header("Content-Type", ctype)
        if stream and status == 200:
            self.send_header("Transfer-Encoding", "chunked")
            self.send_header("Cache-Control", "no-cache")
            self.end_headers()
            last_usage, gen, buf = None, None, b""
            while True:
                chunk = r.read1(65536) if hasattr(r, "read1") else r.read(65536)
                if not chunk:
                    break
                self.wfile.write(b"%x\r\n%s\r\n" % (len(chunk), chunk))
                self.wfile.flush()
                buf += chunk
                while b"\n" in buf:
                    line, buf = buf.split(b"\n", 1)
                    if line.startswith(b"data:") and b"{" in line:
                        try:
                            o = json.loads(line[5:].strip())
                        except ValueError:
                            continue
                        gen = gen or o.get("id")
                        if o.get("usage"):
                            last_usage = o
            self.wfile.write(b"0\r\n\r\n")
            rec.update(status=status, usage=usage_of(last_usage), id=gen)
        else:
            data = r.read()
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)
            try:
                o = json.loads(data)
                rec.update(usage=usage_of(o), id=o.get("id"))
                if status != 200:
                    rec["error"] = json.dumps(o.get("error"))[:400]
            except ValueError:
                rec["error"] = data[:300].decode(errors="replace")
            rec["status"] = status
        rec["latency"] = round(time.time() - t0, 2)
        log(rec)


class S(socketserver.ThreadingMixIn, http.server.HTTPServer):
    daemon_threads = True
    allow_reuse_address = True


if __name__ == "__main__":
    print(f"meter on {HOST}:{PORT} model={MODEL} cap={CAP}", flush=True)
    S((HOST, PORT), H).serve_forever()

def tree_hash(d):
    h = hashlib.sha256()
    for root, dirs, files in os.walk(d):
        dirs[:] = sorted(x for x in dirs if x != "__pycache__")
        for f in sorted(files):
            p = os.path.join(root, f)
            try:
                if os.path.isfile(p) and os.path.getsize(p) < 2_000_000:
                    h.update(os.path.relpath(p, d).encode() + b"\0" + open(p, "rb").read() + b"\0")
            except OSError:
                pass
    return h.hexdigest()
