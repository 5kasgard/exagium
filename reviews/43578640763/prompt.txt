# Pre-registration: bench-5, NVIDIA NIM as a second agent pool

Written 2026-11-14 before any registered run. Author: Claude (chose the setup; not an arm). It follows `router/bench3/PREREG.md` and the pool probe in `router/probe.py` (project doc `forge-free-pools.md`).

**Every rule below is code in `router/bench5/decide.py`.** `decide.py selftest` runs before each batch. It runs bench-3's own selftest first, then bench-5's. Where this text and the code differ, the code is the rule and the difference is a defect to report. The status (`router-runs:bench/bench5/STATUS.md`) is generated by that code.

## Why
The Forge's best-measured free worker is Nemotron 3 Ultra (bench-3 arm A: 6 of 6 clean passes so far). Its only agent pool is OpenRouter's free allowance: 1,000 requests a day, shared by every bench. NVIDIA NIM serves the same model free for development and research. The probe found it answers exactly (3 of 3) and reports the same prompt token count as OpenRouter (36 for 36). It does not show whether NIM can carry agent work, or whether the model performs the same there.

## Hypotheses
- **C. Capacity.** NIM serves at least 21 Nemotron agent attempts inside one UTC day, with no refusal.
- **P. Pass rate.** On bench-3's tasks, Nemotron on NIM is usable (lower end of its 95% interval at least 50%) and not detectably worse than the same model on OpenRouter (bench-3 arm A).
- If C and P both hold, the router gets NIM as its second agent pool. If either fails, it does not.

## What is the same as bench-3 (checked, not assumed)
- Agent: OpenHands SDK v1.61.0, image `agent-server:1.61.0-python`, the default agent, iteration cap 80, a 35-minute cap per attempt.
- Tasks T1–T3, the task text, the grader, the hidden tests and the pass-to-pass lists.
- The workspace is the only mount. The full checkout is deleted before the agent starts. Grading runs in a container with no network, no key and no token.
- `run_agent.py`, `measure.py` and `grade.py` are bench-3's files. The workflow checks their sha256 against the values below before each attempt, and stops if any differs:
  - `router/bench3/run_agent.py` 7a5f5e7617be78bd757bff6b0afe7a209b3eb79ed7b3e82244e367af461e473e
  - `router/bench3/measure.py` 3fe4e1c4e6d4d6ea8132297dc06cbf74d3b5c3617342fc877d28c0ca8ca78edf
  - `router/bench/grade.py` 6e3c5fc9934cc44924ca6da2bdc5a22e0d43244ebb2e7c8a8dcbe173958ba9e1
- Endings, counted attempts, clean passes, the Clopper-Pearson interval, provider retries (3 cuts make a `provider_cut` cell), instrument faults (bench-3's 2026-11-14 amendment) and the void rule: `decide.py` imports these from `router/bench3/decide.py`. It does not copy them.
- The no-agent control Z runs once per task and must fail all 3, or the run is void.

## What changes, and why
- **Provider:** `nvidia_nim/nvidia/nemotron-3-ultra-550b-a55b` through LiteLLM's built-in NIM provider (base `https://integrate.api.nvidia.com/v1`), with the `NVIDIA_API_KEY` secret. The workflow refuses any other model.
- **One arm, N.** 7 repeats per task, 21 attempts. 21 is the C threshold, and 21 of 21 puts the interval's lower end at 84%.
- **No allowance reading.** NIM sends no rate-limit headers (0 of 5 probe runs) and publishes no daily limit. NVIDIA staff wrote in September 2025 that the credit system was replaced by unpublished per-model rate limits; forum posts report about 40 requests a minute. So the plan is every open cell, and the measurement is C itself.
- **4 attempts in parallel.** An agent call took 12.6–86.8 s on NIM in the probe. At 4 agents this stays under 40 requests a minute unless calls take under 6 s. The SDK retries short rate-limit refusals itself; only a refusal that ends an attempt counts against C.
- **Tighter network seal.** NIM resolves to 2 fixed addresses (AWS Global Accelerator: 99.83.136.103 and 75.2.113.119 on 2026-11-14). Containers may reach DNS and those addresses on port 443, nothing else. Before each attempt a container must reach NIM and be refused by github.com and by openrouter.ai, or the attempt does not start. bench-3's seal allowed all of Cloudflare's ranges, so this one is stricter.
- **One more provider pattern.** A refusal for credit or payment (`402`, "insufficient credits" and similar) is a `provider_error`: not counted, retried. bench-3 never saw one. Timeouts and harness crashes keep their meaning.
- **Start times.** Each attempt records `started_utc` (UTC, when its workspace was ready) and the parallel count.
- **First batch timing.** The workflow refuses to start the first registered batch at 18:00 UTC or later, so it cannot cross midnight UTC.

## Decisions, fixed now
- **C** reads only the first registered batch that ran agent attempts, counting every agent attempt in it, counted or not (capacity is about what the provider served).
  - **Fails** if any attempt's error names a refusal: `429`, rate limit, `RESOURCE_EXHAUSTED`, quota, `402`, payment, credit, `403`, forbidden.
  - **Holds** if there is no refusal, the batch has at least 21 agent attempts, and all of them started on the same UTC day.
  - **Inconclusive** otherwise (fewer than 21 attempts, a missing start time, or the batch crossed a UTC day).
  - A server fault (5xx, timeout) is not a refusal: the provider still served that attempt. It is not counted for P and its cell is retried.
  - C is a lower bound at 4 in parallel. It does not measure NIM's real daily limit if that limit is higher.
- **P**, from N's counted attempts and bench-3 arm A's counted attempts:
  - **Usable**: N's clean passes over counted attempts, Clopper-Pearson 95%, as bench-3.
  - **Worse**: two-sided Fisher exact p < 0.05 and N's rate below A's.
  - **Holds** if N's lower end is at least 50%, A has at least one counted attempt, and N is not worse. A detectably better N still holds.
  - **Fails** if N's upper end is under 50%, or N is worse.
  - **Inconclusive** otherwise.
- **Final** only when bench-5 is complete, every bench-3 arm-A cell is done, and the run is not void. Until then STATUS says "Not final".
- **Harness**: reported with bench-3's rule (holds at 7/9 or more with no crash).
- **Reported, no verdict:** median calls per attempt, wall seconds per call and prompt tokens per call, for N and A. A large gap in prompt tokens per call would show a hidden prompt (the probe found one on Nara: 304 vs 36).

## Spend
$0. The NIM key is a free NVIDIA Developer Program key with no payment method, used for research and testing as its terms allow. Worst case 21 × 80 = 1,680 requests plus retries. No OpenRouter allowance is used, so bench-3 and bench-4 are not slowed. GitHub-hosted runners on a public repo.

## Known limits, stated now
- Bench-3's limits all apply: three tasks in one file from this repo's public history; repeats are not independent draws of "a task"; calls counted from response ids.
- The two arms ran at different times and under different loads. A difference could come from the time and not the provider.
- NIM may serve a different build of the model (quantisation, context length or a default system prompt). P tests the result, not the cause.
- Fisher's test with about 21 and 15 attempts detects only large differences. "Not detectably worse" is weak evidence of "the same".
- Concurrency: bench-5 has its own group, so it can push to `router-runs` while bench-3 or bench-4 does. bench-5 retries its own push. A bench-3 or bench-4 push that loses this race fails, and its cells run again in a later batch.
- NIM's trial terms let NVIDIA change limits at any time. A C result describes the day it was measured.

## Pilot
One attempt (N on T2) and one control, `mode=pilot`, before registering. It counts for nothing. It must show: the seal check passes; the model name sent is the arm's; real calls; a label from the list.

"""bench-5: NVIDIA NIM as a second agent pool. Every pre-registered rule as code. Standard library only.

  decide.py selftest                 every ending maps to exactly one label; every rule returns a verdict
  decide.py plan DIR                 JSON list of the open cells (no allowance to read: NIM publishes none)
  decide.py status DIR [BENCH3_DIR]  STATUS.json and STATUS.md (markdown on stdout, JSON to DIR/STATUS.json)

The labels, the interval and the cell rules are bench-3's own code (router/bench3/decide.py), imported, not
copied, so arm N is judged exactly as bench-3's arm A is. Added here: one more provider pattern (credit or
payment refusals), the capacity rule C and the comparison rule P. PREREG.md states the same rules in words;
where the two differ, this file is the rule and the difference is a defect to report.

import datetime, glob, importlib.util, json, math, os, re, statistics, sys

_here = os.path.dirname(os.path.abspath(__file__))
_b3 = next((p for p in (os.path.join(_here, "bench3_rules.py"), os.path.join(_here, "..", "bench3", "decide.py"))
            if os.path.exists(p)), None)
_spec = importlib.util.spec_from_file_location("bench3_rules", _b3)
b3 = importlib.util.module_from_spec(_spec)
_spec.loader.exec_module(b3)

MODEL = "nvidia_nim/nvidia/nemotron-3-ultra-550b-a55b"
ARMS = {"N": (MODEL, "NVIDIA, served by NVIDIA NIM")}
B3_ARM = "A"                       # the same model on OpenRouter, in bench-3, same harness
TASKS, REPS = ["T1", "T2", "T3"], 7
MAX_TRIES = b3.MAX_TRIES
ENDS, COUNTED, CRASH = b3.ENDS, b3.COUNTED, b3.CRASH
INSTRUMENT = b3.INSTRUMENT
# NIM-only addition: a refusal for credit or payment is the provider's, not the worker's. bench-3 never saw one.
EXTRA_PROVIDER = re.compile(r"\b402\b|PaymentRequired|insufficient (credit|balance)|credits? (exhausted|exceeded)", re.I)
# Capacity: an attempt the provider refused (rate, quota, credit or permission), as opposed to a server fault.
REFUSAL = re.compile(r"\b429\b|RateLimit|RESOURCE_EXHAUSTED|quota|\b402\b|PaymentRequired|credit|\b403\b|Forbidden", re.I)
C_MIN = 21                         # attempts that must be served inside one UTC day for C to hold
ALPHA = 0.05


def _errtext(run, events):
    errs = [e for e in events if e.get("kind") == "ConversationErrorEvent"]
    return (run.get("error") or "") + " " + " ".join(f"{e.get('code')} {e.get('detail')}" for e in errs)


def classify(run, events, control=False):
    """bench-3's labels in bench-3's order, with one more provider pattern checked where bench-3 checks its own."""
    lab = b3.classify(run, events, control)
    if lab in ("unclassified", "iteration_cap", "stuck", "finished") and EXTRA_PROVIDER.search(_errtext(run, events)):
        err = run.get("error") or ""
        if not ("rc=124" in err or "rc=137" in err or err.startswith("harness")):
            return "provider_error"
    return lab


reconcile, cells, interval = b3.reconcile, b3.cells, b3.interval


def load(d):
    out = []
    for f in sorted(glob.glob(os.path.join(d, "*", "*", "result.json"))):
        rp = os.path.join(os.path.dirname(f), "run.json")
        try:
            run = json.load(open(rp)) if os.path.exists(rp) else None
        except (ValueError, OSError):
            run = None
        r = reconcile(json.load(open(f)), run)
        r["_err"] = _errtext(run or {}, []) if run else ""
        r["_prompt_tokens"] = ((run or {}).get("tokens") or {}).get("prompt_tokens") if isinstance(run, dict) else None
        out.append(r)
    return out


def plan(results):
    done = cells(results)
    todo = [{"task": t, "arm": "Z", "model": "none", "rep": 0} for t in TASKS if (t, "Z", 0) not in done]
    for rep in range(REPS):
        for t in TASKS:
            if (t, "N", rep) not in done:
                todo.append({"task": t, "arm": "N", "model": MODEL, "rep": rep})
    return todo, len([c for c in todo if c["arm"] != "Z"])


def _day(r):
    s = r.get("started_utc")
    try:
        return datetime.datetime.fromisoformat(str(s).replace("Z", "+00:00")).date().isoformat()
    except ValueError:
        return None


def capacity(results):
    """C, read from the first registered batch that ran agent attempts. Uncounted attempts count here too:
    capacity is about what the provider served, not about what the worker achieved."""
    agents = [r for r in results if r.get("arm") == "N" and r.get("end") != "skipped_budget" and not r.get("pilot")]
    if not agents:
        return {"verdict": "inconclusive", "why": "no registered agent attempt yet"}
    first = min(agents, key=lambda r: int(r.get("run_id") or 0))["run_id"]
    b = [r for r in agents if r.get("run_id") == first]
    days = sorted({_day(r) for r in b} - {None})
    refused = [r for r in b if REFUSAL.search(r.get("_err") or "")]
    served = sum(r.get("calls") or 0 for r in b)
    out = {"batch": first, "attempts": len(b), "calls_served": served, "refused": len(refused), "utc_days": days,
           "parallel": max((r.get("parallel") or 0) for r in b)}
    if refused:
        v, why = "fails", f"NIM refused {len(refused)} of {len(b)} attempts in the batch"
    elif len(b) >= C_MIN and len(days) == 1 and all(_day(r) for r in b):
        v, why = "holds", f"{len(b)} attempts ({served} calls) served in one UTC day with no refusal"
    else:
        v, why = "inconclusive", "fewer than 21 attempts, a missing start time, or the batch crossed a UTC day"
    return dict(out, verdict=v, why=why)


def fisher(k1, n1, k2, n2):
    """Two-sided Fisher exact p for the 2x2 table [[k1, n1-k1], [k2, n2-k2]]."""
    K, N = k1 + k2, n1 + n2
    if n1 == 0 or n2 == 0:
        return 1.0

    def pmf(x):
        return math.comb(K, x) * math.comb(N - K, n1 - x) / math.comb(N, n1)
    p0 = pmf(k1)
    lo, hi = max(0, K - n2), min(K, n1)
    return min(1.0, sum(pmf(x) for x in range(lo, hi + 1) if pmf(x) <= p0 * (1 + 1e-9)))


def compare(n_k, n_n, a_k, a_n, a_complete):
    """P. holds: N usable (lower end >= 50%) and not detectably worse than bench-3 arm A (worse = Fisher p < 0.05
    with N's rate lower; a detectably better N still holds).
    fails: N's upper end under 50%, or N detectably worse than A (p < 0.05 and N's rate lower).
    Inconclusive otherwise, and final only when both sides are complete."""
    lo, hi = interval(n_k, n_n)
    p = fisher(n_k, n_n, a_k, a_n)
    worse = a_n > 0 and n_n > 0 and p < ALPHA and n_k * a_n < a_k * n_n
    if n_n == 0:
        v = "inconclusive"
    elif hi < 0.5 or worse:
        v = "fails"
    elif lo >= 0.5 and a_n > 0:
        v = "holds"
    else:
        v = "inconclusive"
    return {"n_clean": n_k, "n": n_n, "low": round(lo, 3), "high": round(hi, 3), "a_clean": a_k, "a_n": a_n,
            "fisher_p": round(p, 4), "verdict": v, "a_complete": a_complete}


def bench3_arm_a(d):
    if not d or not os.path.isdir(d):
        return 0, 0, False, []
    rs = b3.load(d)
    done = b3.cells(rs)
    got = [v for (t, a, r), v in done.items() if a == B3_ARM and not isinstance(v, str) and v["end"] in COUNTED]
    k = sum(1 for r in got if r["passed"] and r["clean"])
    complete = all((t, B3_ARM, r) in done for t in b3.TASKS for r in range(b3.REPS))
    return k, len(got), complete, got


def _per_call(rs, key):
    v = [r[key] / r["calls"] for r in rs if r.get(key) and r.get("calls")]
    return round(statistics.median(v), 1) if v else None


def status(results, b3dir=None):
    done = cells(results)
    counted = [v for v in done.values() if not isinstance(v, str) and v["end"] in COUNTED]
    controls = [v for v in done.values() if not isinstance(v, str) and v["end"] == "control"]
    _, open_n = plan(results)
    icut = any(v == "instrument_cut" for v in done.values())
    rs = [v for (t, a, r), v in sorted(done.items(), key=lambda kv: (kv[0][2], kv[0][0])) if a == "N" and not isinstance(v, str)]
    k = sum(1 for r in rs if r["passed"] and r["clean"])
    ak, an, acomp, arows = bench3_arm_a(b3dir)
    s = {"complete": open_n == 0 and len(controls) == len(TASKS) and not icut, "open_cells": open_n, "counted": len(counted),
         "provider_cut": sorted(k_ for k_, v in done.items() if v == "provider_cut"),
         "instrument_cut": sorted(k_ for k_, v in done.items() if v == "instrument_cut"),
         "control_ok": len(controls) == len(TASKS) and not any(c["passed"] for c in controls),
         "void": any(c["passed"] for c in controls),
         "seal": "holds" if not any(r["outside_paths"] for r in counted) else "broken",
         "egress_drops": sum(r.get("egress_drops") or 0 for r in counted),
         "ends": {e: sum(1 for r in counted if r["end"] == e) for e in ENDS if any(r["end"] == e for r in counted)},
         "instrument_faults": sum(1 for r in results if r["end"] == INSTRUMENT),
         "provider_errors": sum(1 for r in results if r["end"] == "provider_error")}
    ok = sum(1 for r in counted if r["end"] not in CRASH)
    s["harness"] = {"no_crash": ok, "n": len(counted), "verdict": b3.share_verdict(ok, len(counted))}
    s["capacity"] = capacity(results)
    s["compare"] = compare(k, len(rs), ak, an, acomp)
    s["final"] = s["complete"] and acomp and not s["void"]
    s["second_pool"] = ("yes" if s["capacity"]["verdict"] == "holds" and s["compare"]["verdict"] == "holds" else
                        "no" if "fails" in (s["capacity"]["verdict"], s["compare"]["verdict"]) else "undecided")
    s["report"] = {  # no verdict: reported for routing
        "N": {"median_calls": statistics.median([r["calls"] for r in rs if r.get("calls") is not None] or [0]),
              "wall_s_per_call": _per_call(rs, "wall_s"), "prompt_tokens_per_call": _per_call(rs, "_prompt_tokens")},
        "A": {"median_calls": statistics.median([r["calls"] for r in arows if r.get("calls") is not None] or [0]),
              "wall_s_per_call": _per_call(arows, "wall_s"),
              "prompt_tokens_per_call": _per_call([dict(r, _prompt_tokens=(r.get("tokens") or {}).get("prompt_tokens")) for r in arows], "_prompt_tokens")}}
    return s

    L = ["# bench-5 status (generated by decide.py; not hand-edited)", "",
         *(["**VOID: a no-agent control passed. No verdict below stands.**", ""] if s["void"] else []),

         f"- Complete: **{s['complete']}** ({s['counted']} counted attempts, {s['open_cells']} cells open); "
         f"bench-3 arm A complete: **{p['a_complete']}**; verdicts final: **{s['final']}**",
         f"- Control fails all tasks, as required: **{s['control_ok']}**",
         f"- Seal: **{s['seal']}**; blocked outbound connections: {s['egress_drops']}",
         f"- Harness (no crash): {s['harness']['no_crash']}/{s['harness']['n']}, **{s['harness']['verdict']}**",
         f"- Endings: {s['ends']}; provider errors (not counted, retried): {s['provider_errors']}; instrument faults: {s['instrument_faults']}",
         f"- **C, capacity: {c['verdict']}.** {c.get('why', '')}. "
         f"Batch {c.get('batch')}: {c.get('attempts')} attempts, {c.get('calls_served')} calls, {c.get('refused')} refused, "
         f"UTC days {c.get('utc_days')}, parallel {c.get('parallel')}",
         f"- **P, pass rate vs arm A: {p['verdict']}.** N {p['n_clean']}/{p['n']} clean "
         f"({round(100 * p['low'])}–{round(100 * p['high'])}%); A {p['a_clean']}/{p['a_n']}; Fisher p = {p['fisher_p']}",
         f"- **Second agent pool: {s['second_pool']}**",
         f"- Provider-cut cells: {s['provider_cut'] or 'none'}; instrument-cut cells: {s['instrument_cut'] or 'none'}", "",
         "Reported, no verdict:", "", "| | Median calls | Wall s per call | Prompt tokens per call |", "|---|---|---|---|"]
    for a, v in s["report"].items():
        L.append(f"| {a} | {v['median_calls']} | {v['wall_s_per_call']} | {v['prompt_tokens_per_call']} |")
    if not s["final"]:
        L += ["", "**Not final: every verdict above is provisional and may change.**"]
    return "\n".join(L) + "\n"


def selftest():
    b3.selftest()   # the imported rules still pass their own tests
    # 1. labels: bench-3's, plus credit refusals as provider errors; timeouts and harness crashes keep their meaning
    seen = set()
    for control in (False, True):
        for skipped in (False, True):
            for st in ("ConversationExecutionStatus.FINISHED", "ConversationExecutionStatus.STUCK", "ConversationExecutionStatus.ERROR", ""):
                for e in (None, "harness: boom", "harness: no run.json (agent step rc=124)", "run: MaxIterationsReached",
                          "run: RateLimitError 429", "run: BadRequestError 402 insufficient credits", "run: ValueError: odd"):
                    lab = classify({"status": st, "error": e, "skipped": skipped}, [], control)
                    assert lab in ENDS, lab
                    seen.add(lab)
    assert seen == set(ENDS), set(ENDS) - seen
    assert classify({"status": "x", "error": "run: APIError 402 Payment Required"}, []) == "provider_error"
    assert classify({"status": "x", "error": "run: ValueError: odd"}, []) == "unclassified"
    assert classify({"status": "x", "error": "harness: no run.json (agent step rc=124) 402"}, []) == "timeout"
    assert classify({"status": "ConversationExecutionStatus.FINISHED", "error": None}, []) == "finished"
    ev = [{"kind": "ConversationErrorEvent", "code": "BadRequestError", "detail": "insufficient credits"}]
    assert classify({"status": "ConversationExecutionStatus.ERROR", "error": "run: x"}, ev) == "provider_error"

    def res(t, rep, end, p=False, clean=True, arm="N", **kw):
        return dict({"task": t, "arm": arm, "rep": rep, "end": end, "passed": p, "clean": clean, "outside_paths": [],
                     "calls": 40, "actions": 40, "wall_s": 800.0, "run_id": "100", "pilot": False,
                     "started_utc": "2026-11-14T10:00:00Z", "parallel": 4, "_err": "", "model": MODEL}, **kw)
    # 2. plan: controls first, then repeat-major order, 21 cells
    p0, n0 = plan([])
    assert n0 == 21 and [c["arm"] for c in p0[:3]] == ["Z"] * 3 and p0[3] == {"task": "T1", "arm": "N", "model": MODEL, "rep": 0}
    assert p0[4]["task"] == "T2" and p0[6]["rep"] == 1
    full = [res(t, 0, "control", arm="Z") for t in TASKS] + [res(t, r, "finished", p=True) for t in TASKS for r in range(REPS)]
    assert plan(full)[1] == 0
    # 3. capacity
    assert capacity(full)["verdict"] == "holds" and capacity(full)["calls_served"] == 21 * 40
    one_refused = full[:-1] + [res("T3", 6, "provider_error", _err="run: RateLimitError 429 Too Many Requests")]
    assert capacity(one_refused)["verdict"] == "fails" and capacity(one_refused)["refused"] == 1
    server_fault = full[:-1] + [res("T3", 6, "provider_error", _err="run: ServiceUnavailable 503")]
    assert capacity(server_fault)["verdict"] == "holds"         # a 5xx is not a refusal; the attempt was still served
    crossed = full[:-1] + [res("T3", 6, "finished", p=True, started_utc="2026-11-15T00:05:00Z")]
    assert capacity(crossed)["verdict"] == "inconclusive"
    short = [r for r in full if not (r["arm"] == "N" and r["rep"] == 6)]
    assert capacity(short)["verdict"] == "inconclusive"
    later = full + [res("T1", 0, "provider_error", run_id="200", _err="429")]
    assert capacity(later)["verdict"] == "holds" and capacity(later)["batch"] == "100"   # only the first batch counts
    pilots = [res("T1", 0, "provider_error", run_id="50", pilot=True, _err="429")] + full
    assert capacity(pilots)["batch"] == "100"                                             # pilots never count
    assert capacity([])["verdict"] == "inconclusive"

ENDS = ["control", "skipped_budget", "timeout", "harness_crash", "provider_error",
        "iteration_cap", "stuck", "finished", "unclassified"]
COUNTED = {"timeout", "harness_crash", "iteration_cap", "stuck", "finished", "unclassified"}
CRASH = {"harness_crash", "unclassified"}
PROVIDER = re.compile(r"RateLimit|\b429\b|RESOURCE_EXHAUSTED|quota|LLMAuthenticationError|APIConnectionError"
                      r"|ServiceUnavailable|\b50[234]\b|Timeout|timed out", re.I)


def classify(run, events, control=False):
    """One label per attempt. The first matching line wins; the order is part of the rule."""
    if control:
        return "control"
    if run.get("skipped"):
        return "skipped_budget"
    err = run.get("error") or ""
    errs = [e for e in events if e.get("kind") == "ConversationErrorEvent"]
    codes = [str(e.get("code")) for e in errs]
    if "rc=124" in err or "rc=137" in err:
        return "timeout"
    if err.startswith("harness"):
        return "harness_crash"
    if PROVIDER.search(err + " " + " ".join(c + " " + str(e.get("detail")) for c, e in zip(codes, errs))):
        return "provider_error"
    if "MaxIterationsReached" in codes or "MaxIterationsReached" in err:
        return "iteration_cap"
    status = str(run.get("status", "")).upper()
    if status.endswith("STUCK"):
        return "stuck"
    if status.endswith("FINISHED") and not err and not codes:
        return "finished"
    return "unclassified"

def cells(results):
    """(task, arm, rep) -> the counted result, 'provider_cut', 'instrument_cut', or absent while still open."""
    done, tries, faults = {}, {}, {}
    for r in results:
        key = (r["task"], r["arm"], r["rep"])
        if r["end"] in COUNTED or r["end"] == "control":
            done.setdefault(key, r)   # the first counted result stands; a rerun never replaces it
        elif r["end"] == "provider_error":
            tries[key] = tries.get(key, 0) + 1
        elif r["end"] == INSTRUMENT:
            faults[key] = faults.get(key, 0) + 1
    for key, n in tries.items():
        if key not in done and n >= MAX_TRIES:
            done[key] = "provider_cut"
    for key, n in faults.items():   # amendment 2026-11-14: a fault that recurs cannot loop forever
        if key not in done and n >= MAX_TRIES:
            done[key] = "instrument_cut"
    return done
