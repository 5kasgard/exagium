=> A Go or Rust verifier that uses its standard JSON encoder + sort_keys
   will NOT produce the same digest as Python's json.dumps(sort_keys=True).
   RFC 8785 JCS is the only widely-agreed cross-language canonical form.
   Recommendation: exagium should hash the *stored bytes* of the record (the
   UTF-8 bytes committed to git), OR adopt RFC 8785 JCS via a vetted library
   in every language that consumes the digest.
