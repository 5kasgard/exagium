## Reported (3)
- **method**: A fixed labeled dataset can be repeatedly evaluated and changes detected using an exact McNemar test on paired correctness outcomes. — "Zur Reduktion der Evaluationskosten wird ein verkleinertes Monitoring-Teilstichprobe verwendet, und Veränderungen werden mithilfe des exakten McNemar-Tests auf Basis gepaarter Korrektheitsausgänge geprüft." [paper: Statistical Drift Detection for Non-Stationary Black-Box LLM Classifiers, 2026; https://openalex.org/W7217646379]
- **method**: PromptCanary saves a versioned baseline from a fixed suite of prompts and flags regressions on later runs by comparing probe scores. — "The tool runs the suite against a provider, saves the result as a versioned baseline, and on subsequent runs reports exactly which probes regressed, by how much, and against which prompt." [paper: PromptCanary Detecting Silent Behavioral Drift in Large Language Model APIs, 2026; https://doi.org/10.21203/rs.3.rs-10355583/v1]
- **result**: The Behavioral Shift Auditing test can detect meaningful changes in behavior distributions using only a few hundred probe examples. — "we find that the test is able to detect meaningful changes in behavior distributions using just hundreds of examples." [paper: An Auditing Test To Detect Behavioral Shift in Language Models, 2025; https://doi.org/10.48550/arxiv.2410.19406]
